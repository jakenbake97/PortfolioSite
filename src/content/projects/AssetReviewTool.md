- Started as a tool to make it easier for my friends to be able to review and give me feedback on assets I was 
  creating for my game. Instead of requiring them to download the files and make sure they had the various software 
  I use up to date, I instead wanted to make it as simple as possible for them to review the assets. We already hang 
  out in discord and use it for game-related discussions, so I built a tool that would integrate there to make it 
  seamless for reviewing assets.
